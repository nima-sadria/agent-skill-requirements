# Expertise brief for the first skill

Provide the subject in your own words. The remaining prompts help turn your expertise into a focused skill; short answers and real examples are enough.

| Question | Your answer |
| --- | --- |
| What should the skill be expert in? | |
| Who will use it, and for what outcome? | |
| Which tasks should it handle? | |
| Which similar tasks are outside scope? | |
| What inputs or files will it receive? | |
| What should it produce? | |
| Which rules or constraints must it follow? | |
| Which documents or sources define correct behavior? | |
| Which tools, services, or credentials are necessary? | |
| Which operating systems must be supported? | |
| How will you recognize a correct result? | |

Include two or three realistic requests and, if available, an example of a good result. Describe any common mistake that requires specialist judgment to avoid. The skill's name and final instructions will follow from this brief.
